# Contributing to Telebirr PHP SDK

First off, thank you for considering contributing to the Telebirr PHP SDK! 

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/telebirr.git`
3. Install dependencies: `composer install`
4. Run tests: `composer test`

## Pull Request Process

1. Create a new branch for your feature or bugfix.
2. Ensure any new functionality includes PHPUnit tests.
3. Update the `README.md` with details of changes if applicable.
4. Open a Pull Request with a clear title and description.

## Code Standards

- We follow PSR-12 coding standards.
- Strict typing (`declare(strict_types=1);`) is required for all new files.
- Return types and parameter types must be explicitly declared.
