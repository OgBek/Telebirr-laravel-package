# Security Policy

## Supported Versions

Currently, all recent versions of the SDK are supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this package (e.g., related to signature verification bypassing, timing attacks, or replay vulnerabilities), please send an e-mail to Bekam Beyene at bbekam60@gmail.com.

All security vulnerabilities will be promptly addressed.

**Do NOT open a public issue for security-related vulnerabilities.**
