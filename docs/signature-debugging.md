# Debugging Telebirr Signatures

## Error 60200099: Verify the sign field failed

If you encounter this error, it means the public key on Telebirr's server failed to verify the signature generated by your private key.

### Common Causes & Fixes

1. **Incorrect Keys**: Ensure the public key you uploaded to the Telebirr developer portal corresponds exactly to the private key in your `.env`.
2. **Padding Mismatch**: Telebirr uses RSA-PSS in production. Ensure `TELEBIRR_SIGNATURE_PADDING=pss` is set in your `.env`.
3. **Double Encoding**: The SDK handles all URL encoding. Do not manually `urlencode()` parameters before passing them to the SDK.
4. **H5 Signed Fields**: If manually constructing H5 checkout URLs, ensure you ONLY sign `appid`, `merch_code`, `nonce_str`, `prepay_id`, and `timestamp`.

### SDK Diagnostic Tools

The SDK abstracts the complexities of canonical string sorting (which is prone to PHP associative array ordering bugs). If you suspect a sorting issue, you can inspect the generated canonical string:

```php
$signatureService = app(\Bekambeyene\Telebirr\Services\SignatureService::class);
$canonical = $signatureService->buildCanonicalString($payload);
Log::debug($canonical);
```
